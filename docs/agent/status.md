# 프로젝트 상태 기록

## 2026-10-14 — 초기 연결 확인

구현 기준 커밋: `066bb2f33db65660bee62348ab224db9f22e8ee7`.

이 문서는 해당 시점에 확인한 상태 기록이다. 모든 채팅에서 기본으로 읽지 않는다.
과거 기록을 현재 코드의 보장으로 사용하지 말고 작업 명세의 대상 SHA와 실제 코드를 확인한다.

### 확인한 구현

모델 없이 빈 SQL을 한 번 제출하는 연결 확인 코드다. LLM·완성된 에이전트의
성능 기준값으로 사용하지 않는다.

| 위치 | 해당 시점의 책임 |
| --- | --- |
| `agent/server.py` | `/init_session`, `/run_session`, `/health`와 세션 관리 |
| `agent/loop.py` | 빈 SQL을 한 번 제출하고 공식 응답으로 상태 갱신 |
| `agent/environment.py` | 공식 `/submit`, `/phase_transition` HTTP 호출 |
| `scripts/prepare-benchmark.ps1` | 외부 코드·공개 데이터·GT 병합 준비 |
| `scripts/run-evaluation.ps1` | Docker·에이전트 실행과 공식 러너 평가 |
| `scripts/run-smoke.ps1`, `scripts/run-dev30.ps1` | 한 문제·전체 입력 또는 고정 30문제 평가 |
| `tests/` | 모의 HTTP 계약과 개발 세트 선택 검증 |

러너가 `/init_session`으로 상태를 전달하고 `/run_session`으로 실행을 요청한다.
공식 DB 환경(6002)의 `/submit`이 실행·채점하며, 에이전트가 결과를 상태에 기록해 반환한다.
Phase 1 성공에 후속 질문이 있으면 사용자 시뮬레이터(6001)의 `/phase_transition`을 호출한다.
현재 구현은 후속 질문을 저장한 뒤 멈춘다. 재시도·Phase 2 풀이·나머지 도구는 미구현이다.

세션은 `(mode, task_id)`별 메모리에 저장하고 같은 세션 실행은 lock으로 보호한다.
`reset: false`는 기존 세션 재사용, `true`는 새 상태 초기화다.
이 구현에서는 Uvicorn worker 1개를 사용한다. 평가 기본 동시성은 10, 허용 범위는 1~16이다.
이 제약은 세션 저장 방식과 실행 스크립트를 바꾸면 다시 확인한다.

### 평가 구성과 결과

GT와 공개 Lite 데이터 300개를 매칭했다. 고정 개발 세트는 공개 Phase 1 유형 비율
조회 195개·변경 105개에 따라 조회 20개·변경 10개를 선택했다.
문제별 추가 집계 가중치는 없고 공식 Phase 보상 0.7/0.3을 사용했다.

| 평가 범위 | Oracle Phase 1 | Oracle Phase 2 | Oracle 평균 보상 | 빈 SQL 평균 보상 |
| --- | --- | --- | --- | --- |
| 첫 문제 `alien_1` | 1/1 | 1/1 | 1.00 | 0.00 |
| 개발용 30문제 | 30/30 | 26/30 | 0.96 | 0.00 |
| 전체 입력의 첫 10문제 | 10/10 | 9/10 | 0.97 | 0.00 |

30문제·10문제 평가는 동시성 10으로 실행했고 서비스 연결 오류는 없었다.
30문제 oracle의 Phase 2 실패는 `museum_M_4`, `cross_db_M_5`, `virtual_M_4`, `news_M_4`다.
원본 문제·GT·채점기를 수정하거나 실패 문제를 제외하지 않았다.
전체 300문제 평가는 완료 여부를 확인하지 않았다. 이 결과는 연결 확인이며 모델 성능 측정이 아니다.

모델 호출·추가 도구·실패 후 재시도·후속 단계 풀이를 구현할 수 있다.
모델이나 사용자 질문 도구를 추가할 때 API 설정·의존성·비용도 확인한다.
구체적 순서·범위·완료 조건은 새 작업 명세에서 정한다.

### 상태 기록 유지 방법

주요 기능·평가 기준이 바뀌는 시점에 날짜·대상 SHA·검증 근거를 포함한 기록을 추가한다.
매 작업의 상세 진행은 작업 폴더의 보고서에 남기고 여기에는 요약·링크만 필요한 만큼 추가한다.
고정 지침 문서를 진행 상황 때문에 갱신하지 않는다.
