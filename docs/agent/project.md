# 프로젝트 개요

## 목표

BIRD-Interact Lite의 데이터·도구·채점 과정을 사용해 자체 에이전트 루프를 개선하고,
AI agent engineer 지원 시 설계 선택과 평가 근거를 보여주는 프로젝트다.

이 문서는 오래 유지할 프로젝트 목적과 평가 관점을 다룬다.
구현 단계·패키지 버전·설정값·점수·미완료 기능은 이 문서에 기록하지 않는다.

## 평가 관점

주요 개선 대상은 문제를 조사하고, 도구·질문·제출을 선택하며,
피드백을 받아 다음 행동을 결정하는 에이전트 루프다.
모델·프레임워크·저장 방식은 작업 목적에 맞게 선택할 수 있다.

벤치마크의 데이터·실행 환경·채점 규칙으로 결과를 확인하고,
코드 변경과 관찰된 결과 사이의 근거를 남긴다. 프로그램 종료, 문제 성공,
환경 오류를 구분하고 검증 범위에 맞게 결과를 설명한다.

평가는 정답률뿐 아니라 실제 행동 기록·실패 원인·시간·비용도 작업 목적에 맞춰 확인한다.
비교할 때는 문제 목록·코드 SHA·모델 설정·실행 조건을 기록하고,
어떤 조건이 달라졌는지 설명한다.

정답·테스트 케이스는 평가 환경에서 사용한다. 에이전트는 문제 입력과 허용된 도구의
출력으로 해결한다. 원본 문제·GT·채점 규칙을 변경하는 작업은 루프 개선과 구분해
목적과 결과 해석에 미치는 영향을 기록한다.

## 작업 자료

- 공통 행동 지침: [AGENTS.md](../../AGENTS.md).
- 역할별 절차·템플릿: [역할 운영](README.md)과 `roles/`.
- 프로젝트 경과와 확인한 구현 상태: [status.md](status.md). 필요할 때 확인 시점·기준 SHA와 함께 읽는다.
- 작업별 목표·제약·완료 조건·검증 결과: `tasks/<작업 ID>/`의 명세와 보고서.
- 설치와 실행 방법: [setup.md](../setup.md).

새 작업은 최신 사용자 요청·대상 코드·작업 자료를 근거로 판단한다.
과거 상태 기록을 항상 최신인 것으로 취급하지 않는다.
