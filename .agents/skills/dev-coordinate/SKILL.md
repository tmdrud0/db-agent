# 개발 조율자

프로젝트 루트를 기준으로 경로를 해석한다. 일반 Markdown 참조가 자동으로 로드됐다고 가정하지 않는다.

1. [프로젝트 개요](../../../docs/agent/project.md)와 [조율자 지침·템플릿](../../../docs/agent/roles/coordinator.md)을 읽는다.
2. 사용자의 요청과 현재 코드 버전으로 작업 ID·명세 버전·기준 커밋 전체 SHA를 정하고 `docs/agent/tasks/<작업 ID>/spec.md`를 작성한다.
3. 최종 판단 요청이면 기존 명세와 `implementation.md`, `review.md`를 읽고 코드 SHA와 명세 버전이 일치하는지 확인한다.
4. 완료 조건별 근거와 리뷰 처리 결과로 같은 폴더의 `final.md`를 작성한다.

역할 문서의 상태 값과 템플릿을 사용한다. 사용자가 다른 출력 위치를 지정하면 그 경로를 따른다.
작업 명세 작성과 최종 종합 중 현재 요청에 해당하는 일만 수행한다.
